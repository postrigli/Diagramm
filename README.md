# Diagramm

Анализатор места на Android в духе DaisyDisk для macOS: кольцевая диаграмма (sunburst), по которой
видно, куда делось место, и «коллектор» — корзина выбранных файлов с одной кнопкой «Удалить».
Работает с внутренней памятью, SD-картами/USB, **Google Диском** и **Яндекс Диском**.
Интерфейс на русском и английском.

## Возможности

- Сканирование внутренней памяти, съёмных накопителей, Google Диска и Яндекс Диска.
- Интерактивная диаграмма: тап по сектору — зайти в папку, тап по центру — подняться, хлебные крошки,
  мелкие объекты сгруппированы в «Мелкие объекты».
- Масштабирование щипком (pinch-to-zoom до 12×) и перемещение одним пальцем; кнопка «N×» возвращает обзор.
  Внутри секторов, где хватает места, показываются название и размер (текст не переворачивается вверх
  ногами и подбирает направление — вдоль кольца или вдоль радиуса); чем сильнее приближение, тем больше подписей.
- Цвета секторов: каждая папка верхнего уровня получает свой оттенок из фиксированной палитры
  (синий, оранжевый, аква, жёлтый, пурпурный, зелёный, фиолетовый, красный), вложенное сохраняет оттенок
  родителя. Палитра проверена на различимость при протанопии/дейтеранопии (ΔE ≥ 8,4 между соседями)
  и при обычном зрении (ΔE ≥ 19); свободное место и «прочие данные» — нейтральные серые.
- Свободное место и «прочие данные» (система, скрытое) показаны как отдельные сектора — полный круг
  равен ёмкости хранилища.
- Список содержимого с размерами и долями, фильтр по типам (фото, видео, аудио, документы, архивы, приложения).
- Коллектор: отмечаете файлы и папки, внизу растёт счётчик «собрано», затем удаление.
  Вложенность учитывается — размер не считается дважды.
- Удаление: локально — в **корзину Diagramm** (восстановление возможно) или навсегда;
  в облаке — в корзину облака или навсегда.
- Раздел **«Приложения»**: установленные приложения в виде той же диаграммы (приложение → код и библиотеки / данные / кэш),
  ниже список по убыванию размера. Из списка можно отметить приложения в коллектор и удалить их: Android по очереди
  покажет собственное подтверждение для каждого; на странице приложения открываются его системные настройки.
  Системные приложения видны, но не удаляются. Для размеров нужно разрешение «Доступ к данным об использовании»
  (приложение откроет нужную страницу настроек).

## Архитектура

```
core/model      Node (дерево с размерами), Collector, категории файлов, форматирование размеров,
                сборка дерева из «плоских» ответов облаков
core/chart      раскладка sunburst (углы, группировка мелочи, поиск сектора по касанию) — чистый Kotlin
core/storage    интерфейс StorageProvider, локальный сканер, корзина, дерево приложений, поиск дубликатов (в UI не используется)
core/net        OkHttp-обёртка: токен, обновление при 401, повторы при 429/5xx
provider/gdrive Google Drive REST API v3
provider/yandex Яндекс Диск REST API
app             Android: Jetpack Compose, ViewModel, авторизация
```

Всё, кроме `app`, — обычный Kotlin/JVM с юнит-тестами, собирается и тестируется без Android SDK:

```
./gradlew test
```

Модуль `app` подключается автоматически, если найден Android SDK (`ANDROID_HOME`/`ANDROID_SDK_ROOT`
или `sdk.dir` в `local.properties`). Сборка APK:

```
./gradlew :app:assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

Также APK собирается в GitHub Actions (`.github/workflows/android.yml`) — артефакт `diagramm-debug-apk`.

## Подключение облаков

Приложению нужны ваши собственные OAuth-доступы — их нельзя вшить в репозиторий.

### Google Диск

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект и включите **Google Drive API**.
2. Настройте **OAuth consent screen** (тип External, режим Testing), добавьте свой аккаунт в *Test users*
   и scope `https://www.googleapis.com/auth/drive`.
3. Создайте **OAuth client ID** типа **Android**:
   - Package name: `com.diagramm`
   - SHA-1: `3E:F2:B0:56:E9:EB:EF:FC:E7:BA:0E:CD:86:30:4C:60:BF:94:A5:B1`
     (отпечаток ключа `app/diagramm-debug.jks`, которым подписываются и локальные, и CI-сборки).
4. В приложении нажмите «Подключить» у Google Диска. Секрет в приложение вносить не нужно.

Scope `drive` — «restricted»: для личного пользования (Testing, до 100 тестовых пользователей) проверка
Google не требуется; для публикации в Google Play понадобится верификация приложения.

### Яндекс Диск

1. На [oauth.yandex.ru](https://oauth.yandex.ru/) создайте приложение с правами
   `cloud_api:disk.info`, `cloud_api:disk.read`, `cloud_api:disk.write`.
2. Callback URI: `yx<CLIENT_ID>://token` (подставьте ID приложения).
3. Передайте ID сборке — любым из способов:
   - `YANDEX_CLIENT_ID=<id>` в `local.properties`;
   - `./gradlew :app:assembleDebug -PYANDEX_CLIENT_ID=<id>`;
   - переменная окружения `YANDEX_CLIENT_ID` (для CI — секрет репозитория).

## Доступ к файлам на Android

- Android 11+: «Доступ ко всем файлам» (`MANAGE_EXTERNAL_STORAGE`) — приложение само откроет нужную страницу настроек.
- Android 8–10: обычное разрешение на хранилище.
- Каталоги `Android/data` и `Android/obb` других приложений система закрывает — они попадают в сектор
  «Прочие данные» (с Android 11 их нельзя прочитать без root).
- Для публикации в Google Play разрешение «все файлы» требует отдельной декларации (категория «файловый менеджер»).

## Ограничения текущей версии

- Диаграмма появляется после завершения сканирования (во время скана показываются счётчики и путь).
- Размеры файлов — «логические» (`длина файла`), а не занятые блоки на диске.
- Жесты pinch-zoom нет; навигация — тап по сектору/центру и хлебные крошки.
- Корзина Diagramm лежит в скрытой папке `.Diagramm-Trash` на том же накопителе (перемещение мгновенное,
  но место освобождается только после очистки корзины).
