# Подключение Google Диска и Яндекс Диска

Приложению нужны ваши собственные OAuth-доступы: их нельзя вшить в репозиторий. Это делается один раз.
Данные для регистрации:

| | |
|---|---|
| Package name | `com.diagramm` |
| SHA-1 ключа подписи | `3E:F2:B0:56:E9:EB:EF:FC:E7:BA:0E:CD:86:30:4C:60:BF:94:A5:B1` |
| SHA-256 ключа подписи | `B4:E1:34:AE:4B:D5:96:A9:20:29:0E:E4:82:52:88:62:B2:8A:58:7E:03:F9:43:10:61:04:68:90:62:0A:23:A1` |

Отпечатки принадлежат ключу `app/diagramm-debug.jks`, которым подписываются и локальные, и CI-сборки. Проверить:
`keytool -list -v -keystore app/diagramm-debug.jks -storepass android`.

## Google Диск

1. Откройте [Google Cloud Console](https://console.cloud.google.com/) и создайте проект (выбор проекта вверху → «Новый проект»).
2. Включите API: [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com) → «Включить».
3. Откройте [Google Auth Platform](https://console.cloud.google.com/auth/overview) → «Начать»: название приложения (например, Diagramm), ваша почта,
   аудитория **«Внешние» (External)**, контактная почта, согласие с политикой.
4. «Аудитория» (Audience) → «Тестовые пользователи» (Test users) → «Добавить» → ваш Google-аккаунт, которым будете подключать Диск.
5. «Доступ к данным» (Data Access) → «Добавить или удалить области» → найдите `https://www.googleapis.com/auth/drive`
   («Просмотр, изменение, создание и удаление всех файлов на Google Диске»), отметьте, «Обновить» → «Сохранить».
   Если области нет в списке, вставьте её вручную в поле «Добавить области вручную».
6. «Клиенты» (Clients) → «Создать клиент» → тип **Android**: имя любое, пакет `com.diagramm`, SHA-1 из таблицы выше → «Создать».
7. В приложении: главный экран → Google Диск → «Подключить» → выберите аккаунт → экран с предупреждением «Google не проверил это приложение» →
   «Дополнительно» → «Перейти» → разрешите доступ. Идентификатор клиента вносить в приложение не нужно.

Нюансы:
- Пока приложение в режиме «Тестирование», Google сбрасывает согласие каждые **7 дней**: придётся нажимать «Подключить» заново.
  Чтобы убрать это, в «Аудитории» нажмите «Опубликовать приложение» (останется без проверки, с предупреждением и лимитом 100 пользователей).
- Ошибка входа или «DEVELOPER_ERROR»: не совпадают пакет или SHA-1, либо настройки ещё не применились (подождите несколько минут).
- «access_denied»: вашего аккаунта нет в тестовых пользователях.

## Яндекс Диск

1. Войдите в Яндекс и откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new)
   ([документация](https://yandex.ru/dev/id/doc/ru/register-client)). Тип приложения: **«Для авторизации пользователей»**.
2. Название (иконка необязательна, до 1 МБ). **Платформы** → «Мобильные приложения» → Android: пакет `com.diagramm`, **SHA-256** из таблицы выше.
   Callback URI для этой платформы вводить не нужно: используется `yx<ClientID>://token`.
   (Если выбрать «Веб-сервисы», Callback URI придётся ввести после создания: `yx<ClientID>://token`.)
3. **Доступ к данным** → «Яндекс.Диск REST API», отметьте три права: `cloud_api:disk.info`, `cloud_api:disk.read`, `cloud_api:disk.write`.
4. Укажите почту → «Создать приложение». Скопируйте **ClientID** со страницы приложения (список: [oauth.yandex.ru](https://oauth.yandex.ru/)).
5. Передайте ClientID сборке. Для сборок в GitHub:
   [Settings → Secrets and variables → Actions → Variables](https://github.com/postrigli/Diagramm/settings/variables/actions) → «New repository variable»:
   имя `YANDEX_CLIENT_ID`, значение — ваш ClientID. Затем откройте [Actions](https://github.com/postrigli/Diagramm/actions), последний запуск → «Re-run all jobs»
   (после выполнения скачайте новый APK из Artifacts).
   Локальная сборка: строка `YANDEX_CLIENT_ID=...` в `local.properties` или `-PYANDEX_CLIENT_ID=...`.
6. Установите новый APK поверх старого: главный экран → Яндекс Диск → «Подключить» → откроется браузер, войдите и разрешите доступ, после чего вы вернётесь в приложение.

Нюансы:
- У неверифицированного приложения Яндекс показывает предупреждение при выдаче доступа: для личного пользования это нормально.
- Токен действует около года, потом подключите заново.
- Ошибка про redirect_uri: проверьте, что платформа Android указана с верным пакетом и SHA-256, либо добавлен Callback URI `yx<ClientID>://token`.
